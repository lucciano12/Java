Repositorio que contiene una colección de casos de estudio y ejercicios prácticos de Programación Orientada a Objetos (POO) en Java. Cada módulo aborda conceptos clave de la POO a través de problemas reales, progresando desde conceptos básicos hasta diseños más complejos.

Este repositorio documenta mi trayecto de aprendizaje en análisis de problemas, descomposición de soluciones y modelado de sistemas utilizando Java como lenguaje principal.

🎯 Objetivos del Repositorio
Comprender y aplicar conceptos fundamentales de POO: clases, objetos, encapsulación, herencia, polimorfismo.

Resolver problemas reales a través del diseño de soluciones orientadas a objetos.

Practicar buenas prácticas de desarrollo: encapsulación, delegación, composición y mantenibilidad.

Documentar el proceso de análisis, diseño e implementación de soluciones.
